# Proyectos Power Apps

Repositorio de aplicaciones desarrolladas con Microsoft Power Apps para practicar el desarrollo de aplicaciones empresariales, integración de datos y automatización de procesos.

## Tienda de Ropa

Aplicación Canvas desarrollada para administrar y visualizar productos de una tienda de ropa.

### Funcionalidades
- Visualización de productos mediante galerías.
- Conexión con Excel y OneDrive for Business.
- Manejo de imágenes mediante URLs.
- Formularios para consultar y modificar información.
- Navegación entre pantallas.
- Uso de Power Fx para lógica y manipulación de datos.

### Aprendizajes
Durante este proyecto aprendí a conectar Power Apps con fuentes de datos externas, trabajar con galerías, formularios, imágenes y desarrollar lógica mediante Power Fx.

## Control de Asistencias

Aplicación Canvas desarrollada con Microsoft Power Apps y Dataverse para gestionar trabajadores y registros de asistencia mensual.

### Funcionalidades
- Gestión y edición de trabajadores.
- Manejo de imágenes en Dataverse.
- Registro de asistencias y faltas.
- Filtrado por mes y año.
- Uso de columnas Choice y Lookup.
- Uso de ComboBox y listas desplegables.
- Navegación entre pantallas mediante variables.
- Formularios de edición.
- Actualización de registros mediante SubmitForm().
- Uso de Power Fx para filtros y lógica de negocio.

### Modelo de datos

La aplicación utiliza dos tablas principales:

**Trabajadores**
- Nombre
- Apellido
- Correo
- Imagen

**Asistencia mensual**
- Trabajador
- Mes
- Año
- Asistencias
- Faltas

### Aprendizajes
Este proyecto me permitió profundizar en Microsoft Power Apps y Dataverse, trabajando con relaciones entre tablas, tipos de datos de Dataverse, formularios, galerías, filtros dinámicos y navegación basada en variables.

También adquirí experiencia resolviendo problemas relacionados con Option Sets, Lookup, imágenes, ComboBox y actualización de registros.
